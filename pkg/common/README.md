# Common Utilities

Shared environment and string helpers, logging adapters, Prometheus metrics,
authentication-attempt throttling (`ratelimit`), the lab-mode switch
(`labmode`), management reservation and binding helpers (`mgmtpath`),
management TLS file resolution (`mgmttls`), trusted-CA bundle handling
(`trust`), evidence-completeness status types (`evidence`) and retained-telemetry wire types (`telemetry`) used across containd components. See
[Code Boundaries](../../docs/mkdocs/code-boundaries.md) for placement guidance.
